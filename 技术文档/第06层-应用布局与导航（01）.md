1. Pinia 插件、响应过滤和 App Store。

3. SlotArea 左右结构。
4. LayoutDefault 子路由出口。

8. sidebar-page 演示组件。

## 4. 嵌套路由结构

根路由加载 `SlotCenterPanel.vue`，功能页面作为子路由：

```text
/
├── 首页（TEMP）
├── llm-config
├── user-manager
├── sidebar-preview（TEMP）
├── navigation-preview（TEMP）
└── layout-preview（TEMP）

/login（公开路由）
```

业务路由保留：

```ts
meta: {
  requiresAuth: true,
  title: '页面标题',
}
```

登录路由不得添加 `requiresAuth`。

## 5. 功能验收

### 主布局

- 子路由显示在 `LayoutDefault` 的 `router-view` 内。
- 进入页面时 `areaLoading` 产生约 400ms 加载状态。
- 直接刷新子路由不出现空白。
- 页面切换不重新加载整个应用。

### SideBar

- 用户管理菜单能通过路由名称跳转。
- 当前路由显示激活状态。
- 管理员头像菜单显示管理选项。
- 普通用户头像菜单只保留退出能力。
- 退出后 Store 和 `sessionStorage` 被清除。
- 退出后跳转 `/login`。

数据源、权限、术语及 SQL 示例菜单将在对应功能层验证。此前 `SideBar.vue` 保持 `RUNNING`。

### 顶栏

- 显示 `systemTitle`。
- 点击标题按源码打开项目仓库。
- transparent、hasBorder 和 backgroundColor Props 生效。

### 开发导航

- 读取 `router.getRoutes()`。
- 只显示具有 `meta.title` 的非重定向路由。
- 可以按名称跳转静态路由。
- 动态路由参数自动生成 UUID。

### 保留组件

- `nav-octocat.vue` 正常渲染 SVG。
- 源码没有把 `link` 绑定给 `<a>`，保持原样。
- `nav-footer.vue` 的可见模板被源码注释，因此当前为空。
- `sidebar-page.vue` 是未被正式代码引用的演示组件，通过临时验证页覆盖。

# Aix-DB 功能复刻：第 09 层——多数据库适配

## 1. 本层目标

在第 08 层 PostgreSQL 数据源管理基础上，复刻 Aix-DB 的多数据库连接能力：

```text
数据源表单选择数据库类型
  → 按类型生成连接配置
  → POST /datasource/check
  → DatasourceConnectionUtil.test_connection()
  → SQLAlchemy 或数据库原生驱动
  → 执行连接测试
  → 返回连接成功或驱动错误
```

本层只处理数据库类型、连接 URI 和连接测试，不实现表结构、字段列表、数据预览和 SQL 执行。这些功能属于后续层级。

## 4. SQLAlchemy 数据库连接

`build_connection_uri()` 支持五种 SQLAlchemy URI：

```text
mysql       → mysql+pymysql://
pg          → postgresql+psycopg2://
oracle      → oracle+oracledb://
sqlServer   → mssql+pymssql://
ck          → clickhouse+http://
```

用户名和密码使用源码中的 `urllib.parse.quote()` 编码，`extraJdbc` 直接追加到查询参数。

Oracle 保留两种模式：

```text
service_name:
oracle+oracledb://user:password@host:1521?service_name=ORCL

SID:
oracle+oracledb://user:password@host:1521/ORCL
```

连接测试差异：

```text
Oracle      → 不传 connect_timeout，执行 SELECT 1 FROM DUAL
SQL Server  → timeout + login_timeout + encryption=off
其他类型    → connect_timeout，执行 SELECT 1
```

## 5. 原生驱动数据库连接

本层按源码复刻：

```text
达梦
  → dmPython
  → 驱动不存在时返回明确错误

Doris / StarRocks
  → pymysql
  → MySQL 协议
  → connect_timeout 最低 60 秒

Redshift
  → redshift_connector
  → 驱动不存在时返回明确错误

Kingbase
  → psycopg2
  → PostgreSQL 协议

Elasticsearch
  → Elasticsearch Client
  → Basic Auth
  → ping() 判断连接状态
```

`extraJdbc` 使用源码规则解析：

```text
ssl=true&charset=utf8mb4
  → {"ssl": "true", "charset": "utf8mb4"}
```

没有值、缺少等号或包含多个等号的项目不会进入配置字典。

## 8. 接口验证

连接测试继续使用第 08 层接口：

```powershell
$body = @{
    type = "mysql"
    configuration = (@{
        host = "127.0.0.1"
        port = 3306
        username = "root"
        password = "password"
        database = "analytics"
        dbSchema = "analytics"
        extraJdbc = "charset=utf8mb4"
        timeout = 30
        mode = "service_name"
    } | ConvertTo-Json -Compress)
} | ConvertTo-Json

Invoke-RestMethod `
    -Uri "http://127.0.0.1:8088/datasource/check" `
    -Method Post `
    -Headers @{ Authorization = "Bearer <token>" } `
    -ContentType "application/json" `
    -Body $body
```

未启动对应数据库时允许返回真实驱动错误，但不能返回“第 8 层暂不支持数据源类型”。

# Aix-DB 功能复刻：第 11 层——训练数据

## 1. 本层目标

完成 SQL 示例训练数据的管理闭环：

```text
SQL 示例库页面
  → 分页查询与问题搜索
  → 新增问题和示例 SQL
  → 可选关联数据源
  → 编辑训练数据
  → 启用或停用
  → 删除训练数据
  → 写入 t_data_training
```

本层只复刻训练数据 CRUD。根据分层边界，不生成 Embedding，也不接入向量检索和问答链路。

## 3. 数据流

```text
前端 /set/training
  → /sanic/system/data-training/*
  → data_training_api
  → data_training_service
  → t_data_training
     ↘ t_datasource（返回数据源名称）
     ↘ t_ai_model（返回高级应用名称）
```

查询时使用左连接补充数据源名称和高级应用名称；创建、编辑、启停和删除直接操作训练数据表。

## 4. 数据模型

本层复用 `TDataTraining`：

| 字段 | 用途 | 本层规则 |
|---|---|---|
| `id` | 主键 | 自动生成 |
| `oid` | 组织标识 | 保留原项目默认值 `1` |
| `question` | 自然语言问题 | 必填 |
| `description` | 示例 SQL | 页面必填 |
| `datasource` | 数据源 ID | 可空，空值表示全部数据源 |
| `advanced_application` | 高级应用 ID | 可空；本层页面不提供选择器 |
| `enabled` | 是否启用 | 默认 `true` |
| `create_time` | 创建时间 | 新增时写入当前时间 |
| `embedding` | 向量 | 本层固定为 `NULL` |

## 5. 后端服务规则

### 5.1 分页查询

`page_data_training()` 按以下规则查询：

1. 只返回指定 `oid` 的记录。
2. `question` 非空时执行不区分大小写的模糊搜索。
3. 按 `create_time` 倒序排列。
4. 返回 `records`、`total_count`、`current_page` 和 `total_pages`。
5. 左连接返回 `datasource_name` 和 `advanced_application_name`。

### 5.2 新增与重复校验

新增时保留原项目的重复判断语义：

| 作用域参数 | 重复条件 |
|---|---|
| 同时有数据源和高级应用 | 同问题、同组织，且数据源或高级应用任一相同 |
| 只有数据源 | 同问题、同组织、同数据源 |
| 只有高级应用 | 同问题、同组织、同高级应用 |
| 两者均为空 | 同问题、同组织的任意记录 |

问题为空或记录重复时抛出参数错误。新记录的 `embedding` 明确写为 `NULL`。

### 5.3 编辑、启停和删除

- 编辑接口按 ID 更新问题、示例 SQL、数据源、高级应用和启用状态。
- 编辑不会生成或修改 Embedding。
- 启停接口只更新 `enabled`。
- 删除接口接收 ID 列表并批量删除。
- 编辑或启停不存在的记录时返回“Training data not found”。

原项目的既有边界同样保留：重复校验只在新增时执行；编辑、删除和启停按记录 ID 定位；分页路径参数只校验为整数。第 11 层不额外修正这些源码行为。

## 6. 后端接口

四个接口均沿用项目现有 JWT 登录认证，不新增管理员权限：

| 方法 | 路径 | 请求 | 用途 |
|---|---|---|---|
| GET | `/sanic/system/data-training/page/{page}/{size}` | 查询参数 `question` | 分页查询和搜索 |
| PUT | `/sanic/system/data-training/` | 训练数据表单 | 无 ID 时新增，有 ID 时编辑 |
| DELETE | `/sanic/system/data-training/` | `{ "ids": [1, 2] }` | 批量删除 |
| GET | `/sanic/system/data-training/{id}/enable/{enabled}` | 路径参数 | 启用或停用 |

分页记录结构：

```json
{
  "id": 1,
  "question": "本月销售额是多少？",
  "description": "SELECT SUM(amount) FROM orders",
  "datasource": 10,
  "datasource_name": "业务库",
  "advanced_application": null,
  "advanced_application_name": null,
  "enabled": true,
  "create_time": "2026-08-05 14:00:00"
}
```

## 7. 前端操作流程

训练数据页面路由：

```text
/set/training
```

侧边栏已有“SQL 示例库”入口，本层补齐对应路由和页面。页面支持：

- 按问题描述搜索。
- 分页及切换每页数量。
- 新增 SQL 示例。
- 编辑问题、SQL、数据源和启用状态。
- 使用已有 `formatSQL()` 格式化示例 SQL。
- 在列表中直接启停记录。
- 二次确认后删除记录。
- 数据源为空时显示“全部数据源”。

训练数据表格不启用 Naive UI 的 `flex-height`。当前页面容器没有为该模式提供确定的表体高度，启用后虽然数据行已经生成到 DOM，但表体高度会变为 `0px`，造成“新增成功且接口有数据、页面却只显示表头”的现象。这里按内容高度展示列表。

高级应用列按原项目保留；由于原项目此页面尚未实现高级应用列表获取，表单中的高级应用输入同样保持隐藏。

## 8. 手工验收步骤

1. 使用已登录账号进入 `/set/training`。
2. 新增一条问题和示例 SQL，并选择数据源。
3. 确认列表显示数据源名称和创建时间。
4. 搜索问题关键字，确认只显示匹配记录。
5. 编辑问题或 SQL，保存后确认列表刷新。
6. 点击 SQL 格式化按钮，确认文本被格式化。
7. 切换启用状态并刷新页面，确认状态持久化。
8. 删除记录，确认记录从列表消失。
9. 使用同一作用域新增重复问题，确认后端拒绝。
10. 检查数据库，确认本层新增记录的 `embedding` 为 `NULL`。

## 11. 本层未实现范围

以下功能明确不在第 11 层实现：

- 训练问题的 Embedding 生成或更新。
- 向量数据库写入和相似度检索。
- 将训练数据接入 RAG、Text-to-SQL 或聊天问答流程。
- 批量导入、导出训练数据。
- 执行或校验用户填写的示例 SQL。
- 高级应用下拉列表和作用域管理。
- 训练任务、训练进度或模型微调。

本层没有为上述功能添加占位接口或替代逻辑。
